## The Menu

The main **hamburbur** project is a feature packed Gorilla Tag mod menu built in C# for BepInEx.

It focuses on giving you a powerful modding experience while keeping the actual interface clean and easy to navigate.

<p align="center">
    <img src="https://hamburbur.org/menu_front.png" alt="Menu Preview">
</p>

### ✨ Highlights

- Highly customizable themes and UI
- Dedicated plugin system
- AI powered voice features
- VR and desktop controls
- Performance focused systems
- Regular updates for Gorilla Tag changes
- Simple BepInEx installation
- Community maintained tools and services

## First timer?

Want to use hamburbur?

1. Install **BepInEx 5.x** for Gorilla Tag.
2. Install the required dependencies.
3. Download the latest hamburbur release.
4. Place the DLL inside `BepInEx/plugins`.
5. Launch Gorilla Tag.

<div align="center">

### [Download the latest release](https://github.com/hamburbur-org/hamburbur/releases/latest)
